# Client Website Showcase

A collection of independent website projects built to demonstrate web development capabilities and showcase work to potential clients.

## About

This repository is a monorepo containing multiple website projects, organized into separate directories.

Each website is developed independently and can have its own live deployment link.

A central portfolio website will provide an overview of the available projects and allow visitors to explore their live demos.

## Repository Structure

```text
client-website-showcase/
├── portfolio/
├── websites/
├── shared/
│   ├── css/
│   ├── js/
│   └── images/
└── README.md
```

## Technologies

Technologies will vary depending on the requirements of each project.

## Deployment

GitHub Pages will be used to host suitable static websites and the central portfolio.

## Projects

Project descriptions, screenshots, and live demo links will be added as websites are developed.
